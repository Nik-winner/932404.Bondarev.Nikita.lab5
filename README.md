# Интерактивная веб-страница «Волонтёр и социальный активист»

## Информация об авторе

- **ФИО:** Бондарев Никита
- **Учебная группа:** 932404
- **Вариант:** 13

## Реализованная структура

- **Секция «Текущие акции» (`#campaigns`):**
  - Панель управления с кнопками «Скрыть акции» и «+ Добавить акцию».
  - Контейнер `.cards-container` с существующими карточками, имеющими атрибуты `data-id`.
  - Даты оформлены через тег `<time datetime="...">`.
  - В каждую карточку встроена кнопка «Участвовал».

### Реализованные возможности

1. **Поиск элементов:**
   - `getElementById` (через безопасную обёртку `safeGetElement`).
2. **Манипуляции с DOM:**
   - Создание и добавление элементов (`createElement`, `appendChild`, `append`).
   - Удаление элементов (`card.remove()`).
   - Изменение текста (`textContent`), атрибутов (`setAttribute`) и классов (`classList.toggle`, `classList.add`).
3. **Переключение темы:** Кнопка в шапке переключает класс `theme-dark` / `theme-light` у `<body>`, меняя CSS-переменные.
4. **Скрытие/показ блоков:** Кнопка «Скрыть акции» управляет свойством `display` у контейнера карточек.
5. **Обработка ошибок:**
   - Функция `safeGetElement` проверяет существование элемента и выводит `console.warn`, если его нет, предотвращая падение скрипта.
   - Блоки `try...catch` при работе с `localStorage` (на случай отключённого хранилища или переполнения).
   - Валидация данных из `prompt` (проверка на пустую строку).
6. **Сохранение состояния в `localStorage`:**
   - `volunteer_theme`: выбранная тема.
   - `volunteer_campaigns_hidden`: состояние видимости секции акций.
   - `volunteer_custom_campaigns`: массив JSON с данными добавленных пользователем акций.
   - `volunteer_participated`: массив ID карточек, где нажата кнопка «Участвовал».
   - При перезагрузке страницы (`DOMContentLoaded`) все состояния восстанавливаются.

### Логика работы скрипта

1. **При загрузке страницы:**
   - Применяется сохранённая тема.
   - Восстанавливается состояние видимости блока акций.
   - Существующим карточкам назначаются обработчики нажатия на кнопку «Участвовал» (с сохранением в `localStorage`).
   - Из `localStorage` загружаются и отрисовываются ранее добавленные пользователем акции.
2. **Добавление акции:**
   - По клику вызываются `prompt` для ввода названия, даты и описания.
   - При успешной валидации создаётся новая карточка с уникальным `data-id`, кнопками «Участвовал» и «Удалить».
   - Данные сериализуются в JSON и сохраняются в `localStorage`.
3. **Удаление акции:**
   - Вызывается `confirm` для подтверждения.
   - Элемент удаляется из DOM, список в `localStorage` обновляется.
